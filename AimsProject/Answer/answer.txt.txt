No, Java does not allow this.

Because both constructors would have the same parameter type (a single String), Java considers them identical. Java differentiates constructors based on the number, type, and order of parameters, not the parameter names.

Therefore, defining:

DigitalVideoDisc(String title)
DigitalVideoDisc(String category)

will result in a compile-time error due to duplicate constructors.

To solve this, constructors must differ in parameter list, for example:

DigitalVideoDisc(String title, String category)

Conclusion:
Java only allows constructor overloading when the parameter lists are different.

Question: Compare arrays and ArrayList. Why do we use ArrayList<Media> instead of Media[] or DigitalVideoDisc[]?
Trả lời:
Mảng tĩnh (Media[]): Có kích thước cố định ngay từ khi khởi tạo, không thể tự co giãn khi thêm hoặc xóa phần tử. Khó quản lý số lượng phần tử thực tế (phải dùng thêm biến đếm như qtyOrdered).
Mảng động (ArrayList<Media>): Tự động thay đổi kích thước linh hoạt khi ta gọi hàm .add() hoặc .remove(). Hỗ trợ sẵn nhiều phương thức tối ưu như .contains(), .size(), .clear().
Lý do sử dụng: Giỏ hàng (Cart) và Cửa hàng (Store) cần lưu trữ đồng thời nhiều loại sản phẩm khác nhau (Book, CD, DVD). Việc sử dụng ArrayList<Media> vừa tận dụng được tính đa hình (lưu các lớp con vào danh sách của lớp cha), vừa giúp quản lý danh sách sản phẩm linh hoạt mà không sợ bị tràn bộ nhớ hay giới hạn số lượng phần tử.
