# GuiProject

Maven project for Lab 05 GUI programming.

## Packages

- `hust.soict.dsai.swing`: AWT/Swing accumulator and NumberGrid.
- `hust.soict.dsai.javafx`: JavaFX Painter with Pen and Eraser.

## Run

Compile:

```powershell
mvn compile
```

Run JavaFX Painter:

```powershell
mvn javafx:run
```

Run Swing classes from an IDE or with `exec:java` after adding an exec plugin configuration.
